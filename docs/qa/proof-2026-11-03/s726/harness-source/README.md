# SCRUM-726 local measurement source

These are source snapshots of the 16 local measurement and cleanup helpers. Git stores LF line endings; manifest.json records both stored and original SHA-256 hashes plus the original line endings. Reconstructing those line endings is verified to reproduce every original byte. They are audit attachments, not application entry points. Credentials are read by variable name through the repository environment helper; no credential value is included. The absolute paths identify the original Windows test workspace.

The active soak uses these files unchanged. A future measurement must establish its own ZZ TEST fixture, current live source and exclusive proof window before adapting or running them; the original records are retired during cleanup. The source snapshots preserve how requests, timings, stop conditions, independent sale counts and cleanup were measured.
