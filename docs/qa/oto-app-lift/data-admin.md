# SCRUM-193: Data admin access alignment

The live generic data editor remains at `/data` with its model index, schema view, record list, detail and create/edit screens. Its server API is guarded by `requireGlobalAdmin`, which accepts global admin and the original legacy admin role, but rejects operator admin. The client route gate previously allowed operator admin into all six data pages, where the API then refused every request. The route gate now matches the server rule.

The generic editor is a privileged maintenance tool backed by the original model registry. The vault access-item model was removed by SCRUM-463 so credentials cannot bypass the audited vault reveal. SCRUM-466 also removes session, Xero OAuth token and password reset token models from generic access; the normal auth and Xero routes still own those records. User model list/detail/write responses omit the password hash. Other models remain available for maintenance and still need a signed-in data review before a production-data claim.
