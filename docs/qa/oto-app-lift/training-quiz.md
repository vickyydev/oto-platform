# SCRUM-458: Training and quizzes

The Learn page now links to the registered module route and reads questions from a tenant- and branch-scoped detail response. Learners do not receive correct answers before submission. The new quiz route validates one answer per question, scores against stored answers, records an attempt, and records one completion only after a pass; a content-only module can be completed without questions. The best attempt is stored as a percentage for the Learn card. The learner content is rendered as text, so edited markup cannot execute in the browser.

The Studio Training & Quizzes page now lists modules without reading missing `departments` data. Administrators can create, edit and delete modules, set their active state, choose all or selected branches, and edit answer choices and the correct choice. The server validates the tenant's branch IDs, question choices and passing score. Staff and managers can view only; inactive or other-branch modules are hidden from learners. Existing completions remain after an administrator edits questions; no retake policy or question-versioning rule is defined for this lift.

An isolated full-seed probe created global, own-branch, other-branch and content-only modules, plus a temporary other-tenant module. A seeded staff account was temporarily limited to one branch; its original access rows were restored afterward. The API probe passed list/detail scoping, hidden answers, admin-only edits, invalid-answer refusals, failed attempt without completion, passed attempt and retry with one completion, best-score display, zero-question completion, update, delete and other-tenant refusal. Browser checks navigated from Learn to module detail, completed a two-question quiz with no page errors, and created and edited a module in Studio with no page errors. All synthetic modules, attempts, completions, questions, tenant and sessions were removed; residual module/tenant counts were zero. The temporary probe was removed and no test suite was added.
