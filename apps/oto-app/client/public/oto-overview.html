Architecture at a glance

  • Multi-tenant hierarchy — tenant → operator → branch; full data isolation per operator
  • Shared identity — one People record links contracts, schedules, payslips, and training across all modules
  • Role-based access — 5-tier hierarchy (Global Admin → Staff) with per-user module overrides
  • Single deployment — React frontend + Express backend served from one process; no separate login per module

OTO HR

👥

Human Resources & Workforce Management

End-to-end employee lifecycle — hire, contract, schedule, clock in, pay, offboard.

  • 📋
    Contract Templates + E-Sign Rich-text templates with dynamic token substitution. Contracts issued via tokenised public URL — no employee account needed to sign.
  • 👤
    Employee Profiles Full lifecycle records: onboarding, department, role, photo, contract history. Bulk CSV import for large cohorts.
  • 📅
    Scheduling Multi-branch shift builder. Staff view their rota in Ops. Availability preferences feed directly into schedule planning.
  • 🕐
    Timekeeping & Attendance Clock-in/out via kiosk (PIN, QR, face). Live "who's on site" dashboard. Discrepancy flagging before payroll.
  • 💰
    Payroll Configurable pay periods, statutory rules, exception review. One-click Xero export. Self-service payslip portal for staff.
  • 📲
    Reception Kiosk Any tablet becomes a branded branch terminal. Activated via hashed one-time code. Supports PIN, QR, and face check-in.
  • 🔔
    Attention Engine Rule-based proactive alerting. Surfaces expiring probations, unsigned contracts, missing documents before they become problems.
  • 📄
    Policies & Audit Log Rich-text policy editor with staff acknowledgement. Immutable activity logbook for all HR actions with actor and timestamp.
  • 📈
    HR Analytics Headcount by branch/department, turnover trends, attendance rates, payroll summaries — scoped to user's branch access.
  • 🗂️
    Org Chart & Org Structure Live org chart from employee data. Departments, roles, locations all configurable. Casual and contractor pools managed separately.

Task Management · Event Management · Daily Operations

The front-of-house interface used by all staff every working day — and the back-office where managers build the workflows, events, and knowledge that power it.

Event Management (BEO)

  • 🎉
    Event / BEO Planner Full event lifecycle: guest list, RSVP tracking, seating, supplier assignments, staff briefings. Kanban + calendar views.
  • ✨
    AI Fill Paste a raw enquiry email or message — AI extracts event name, date, guest count, requirements, and pre-fills the BEO form.
  • 📧

OTO Intelligence

📊

Revenue & Operations Analytics

Live POS revenue dashboard with AI trend analysis, branch forecasting, and a proprietary headcount engine. No login required.

OTO Intelligence ingests data from multiple point-of-sale systems, normalises it into a central database, and presents live KPIs, trend charts, and forecasts. The database is the sole source of truth — POS APIs are never called on page load, ensuring the dashboard is always fast regardless of third-party API availability.

  • 🔗
    Multi-POS Ingestion Connects simultaneously to Pisell (MD5-signed auth) and Papaya (dual-terminal merge). Includes a 2-hour-window pagination fix that recovers ~25% of Papaya orders silently dropped by a vendor API bug.
  • 🧮
    Headcount Solver Proprietary price-based constraint solver decomposes bundled family ticket packages into individual kid + adult counts — data no POS or generic analytics tool provides natively.
  • 🗂️
    Revenue Category Engine Classifies all POS orders into 6 categories (Tickets, F&B, Merchandise, Events, Nanny/Drop-off, Extras) using product-name and category-name rules. Each daily summary is formula-versioned for auditability.
  • 📈
    Branch Forecasting Per-branch operating models (weekday/weekend targets, category shares, seasonality). AI Trends injects virtual forecast metrics so users can query actual vs. budget directly in conversation.
  • 🔄
    Background Auto-Sync Syncs 5 seconds after startup, then every 5 minutes. Locked months (audited periods) are skipped and preserved even during push-to-production.
  • 🤖
    AI Trends Assistant Conversational chart builder with Phuket tourism context, 6 quick-start presets, and saved conversation history. Forecast lines render dashed; actuals solid.
  • 📆
    Yearly Heatmap Calendar Academic-year 12-month grid with 7-level intensity scale. School calendar events overlaid as dots. Click any day to add an operational note.
  • 🔢
    Formula Registry Every calculation is a named, versioned entity. Visible in the Config tab. Historical records are always re-interpretable regardless of future formula changes.

OTO Marketing Hub

📣

Unified Marketing Analytics

Read-only dashboard aggregating Meta, Google, and website data with period-over-period comparison and a Smart Refresh sync pipeline.

OTO Marketing Hub pulls from Meta (Facebook/Instagram/WhatsApp), Google (Ads/Analytics/Maps), and website analytics into one read-only dashboard. It is intentionally read-only — it never writes back to any source platform. A formal OpenAPI contract is the single source of truth; all client hooks and Zod schemas are auto-generated from it, eliminating type drift between frontend and backend.

  • ⚙️
    Two-Layer Pipeline Layer 1 (raw) stores API responses. Layer 2 (processed) runs SQL aggregations into analytics-ready tables. Clean separation of sync and query concerns.
  • 🛡️
    Triple Fallback Each route tries the DB first, then a live API call, then high-fidelity demo data. Dashboard always renders — even when credentials are absent or rate-limited.
  • 🔄
    Smart Refresh Single endpoint syncs yesterday, today, and any detected data gaps. Frontend refresh button triggers Smart Refresh before re-querying.
  • 📊
    Command Centre Global period-over-period view (e.g., This Month vs. Previous Month) with trend indicators for visibility, followers, engagement, and spend.
  • 📱
    Social Performance Follower growth charts and per-post metrics across Facebook and Instagram — engagement rate, reach, and impressions breakdowns.
  • 🏗️
    Design Sandbox Isolated component preview environment for prototyping UI in isolation. A Vite plugin auto-discovers components and serves a gallery — changes never risk the production dashboard.

AI & Automation

  • ASK OTO (RAG assistant) — retrieval-augmented generation grounded in the business's own knowledge base. Source-cited answers. Explicitly flags out-of-scope questions rather than hallucinating.
  • AI Fill (BEO parser) — paste raw enquiry text; LLM extracts date, guest count, requirements, and special notes and pre-fills the event form.
  • Attention Engine — rule-based HR alerting. Encodes domain knowledge (probation thresholds, contract expiry windows, document gaps) to surface actionable items before they escalate.
  • OTO Intelligence Trends — conversational chart builder with tourism seasonality context; injects virtual forecast metrics server-side for actual vs. budget queries.
  • SMS Automation (Twilio) — drop-off/pickup parent notifications, escalation alerts, password-reset OTPs, phone verification. E.164 normalisation for reliable international delivery.
Grounded AI principle: All AI features are anchored to business-specific data (knowledge articles, POS records, HR rules) rather than applied generically. This makes outputs auditable and operationally trustworthy.

Proprietary IP Highlights

Each item below represents a novel capability engineered specifically for this vertical — not replicable from off-the-shelf tools.

Architecture

Unified Multi-Module Platform

HR, Ops, and analytics share one identity, one permission model, one database. A single person record anchors contracts, schedules, payslips, and training — no sync layer.

AI / NLP

AI Fill — BEO Parser

Unstructured enquiry text (email, WhatsApp, voice transcript) → fully populated event record. LLM extracts date, guest count, requirements, and maps them to the data model.

Rules Engine

Attention Engine

Encodes HR domain knowledge (probation thresholds, contract expiry, document gaps) as rules. Surfaces actionable, prioritised items — not raw notification lists.

AI / RAG

ASK OTO — Grounded AI Assistant

RAG architecture anchored to operator-authored knowledge base. Explicitly declines out-of-scope questions — architecturally enforced, not a prompt instruction.

Workflow

Contract Template + E-Sign Flow

Rich-text editor → token substitution → guided wizard → unique expiring signing URL. Every signing event timestamped. No employee account required.

Security / Hardware

Multi-Modal Kiosk System

Standard tablet → branch reception terminal via hashed one-time activation code. Supports PIN (bcrypt), QR, and face recognition. Configurable expiry and reconnection limits.

Multi-Tenant

Tenant → Operator → Branch Isolation

Three-level data hierarchy enforced at the middleware layer before any business logic. Enables SaaS multi-tenancy and single-tenant enterprise from one codebase.

Communication

Tokenised Public Portal Network

Contract signing, guest RSVPs, supplier briefings, parent check-in — all via cryptographically random expiring URLs. No account creation; full audit trail.

Analytics

Price-Based Headcount Solver

Constraint algorithm decomposes bundled family ticket packages into kid + adult counts using known base prices. Includes free-guardian and drop-off logic. No POS vendor provides this natively.

Analytics

Spec-Driven API + Triple Fallback

OpenAPI contract → auto-generated TanStack hooks + Zod schemas (Orval). Triple fallback (DB → live API → demo data) means the dashboard never shows a blank screen.

Summary

OTO Suite is a five-module platform that covers the full operational and analytical lifecycle of a multi-branch service business: hiring and paying people (OTO HR), managing their daily tasks and events (OTO Ops), understanding revenue in real time (OTO Intelligence), and measuring marketing performance (OTO Marketing Hub) — all underpinned by a shared AI layer.

The platform's IP value lies in the depth of its domain-specific engineering: the headcount solver, the grounded AI assistant, the proactive attention engine, the contract e-sign workflow, and the multi-modal kiosk system are each purpose-built for this vertical and constitute a body of proprietary software that cannot be assembled from generic components.
