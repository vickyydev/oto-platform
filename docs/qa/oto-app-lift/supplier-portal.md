# SCRUM-457: Fix supplier portal

The supplier report-detail route used the wrapper returned by storage as though it were the report, so valid magic links received 403. The portal now checks the nested report's tenant and branch, returns the flat report shape expected by its page, and maps its media to a token-scoped read route. Comment creation uses the actual Fix comment fields. A supplier can mark an open report done once; a repeat attempt returns 409.

Token creation now accepts only branches in the admin's tenant and a valid future expiry. Management uses the server's admin role gate; revocation disables the token while retaining its record. Every public supplier route rejects a malformed, expired or disabled token. Report detail, comments, close and media reads also require the token's tenant and branch, and media must be listed on that report. The token list now reports the stored last-used timestamp and enabled state. The local login diagnostic that logged session IDs was removed while verifying the admin flow.
