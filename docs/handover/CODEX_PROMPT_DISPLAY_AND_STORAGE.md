**The decisions (final; build these, do not reopen them)**
- **The mirror.** Every 60 s the agent writes a consistent copy of `box.sqlite` with SQLite's `VACUUM INTO` (Node's `node:sqlite` supports it) into the directory named by `OTO_BOX_MIRROR_DIR` (an environment variable the service file passes, like `OTO_BOX_HOME`; absent means no mirroring and a one-line note in the status output). The copy is written to a temporary name, checked with `pragma quick_check`, then renamed over `box.sqlite.mirror`; the previous two mirrors are kept as `.mirror.1` and `.mirror.2`. A mirror also runs right after the outbox accepts a new unsent record if the last mirror is older than 10 s, so an outage's sales never wait a full minute. Mirroring never blocks a sale: it runs off the write path and skips a round rather than queueing when the previous one is still running. `oto-box store mirror-now` runs one on demand.
- **The restore.** `oto-box store restore FILE` refuses while the service is running, checks the file with `quick_check`, moves the current `box.sqlite` (and its `-wal`/`-shm`) aside as `box.sqlite.replaced-<time>`, copies the mirror into place, and prints the unsent count it found. The credential and `/etc/oto-box/config` are untouched; the runbook says a box whose drive died is reinstalled from a release, re-registered in the Console, then restored from the mirror.
- **Storage health in the heartbeat.** A `storage` block: free bytes and total bytes of the store's filesystem, whether that filesystem is mounted read-only, the count of I/O errors the store met since start (`EIO`, `EROFS`, `SQLITE_IOERR`, `SQLITE_READONLY`), the mirror's age in seconds and its directory's free bytes (null when no mirror directory). Expand-only on the schema; an old agent that sends no block is simply "unknown".
- **Health conditions**, per box, in the `box.revocations_behind` pattern: `box.storage_failing` when the filesystem is read-only or I/O errors were counted; `box.storage_low` when free space is under 2 GB or under 10 percent; `box.mirror_stale` when a mirror directory is configured and the mirror is older than 10 minutes. Plain wording a manager understands ("The counter box's drive is failing: replace it today; its sales are mirrored" / "…is not mirrored: no mirror directory is configured" and so on). Each clears when the next heartbeat no longer shows the fact.
- No change to WAL or `synchronous = FULL`. No change to the outbox's rules. No installer change: write what the installer must do (the mirror directory, the service's environment line, the journald cap and swap) as a short section at the top of your STATUS block and on the ticket for the planner's SCRUM-711 lane; do not edit `scripts/pi/**`.
